# «اكتشف الفرق» — 30-pair production pilot (candidates, NOT the approved bank)
- spotlib-pilot/: the 30 candidate pairs at 1600 px with exact tap areas (ids p1-*). Nothing here is used by the game.
- pilot_record.json: the record of each pair — automatic check (qc), every independent review round (verdict, notes),
  every fix, the independence check, content decisions, source and licence. The owner's decisions are kept on the review page.
- specs/: the guided-production spec of each pair (and the one rejected by the independent review, w29664845).
- pilot_*_done/skipped.txt: production outcome per source picture; pilot_fixes*.txt: fix rounds; pilot_review*.json: review rounds.
A pair enters the approved bank only after the owner accepts it on the review page.

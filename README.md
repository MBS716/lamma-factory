# lamma-factory
Automated Image Factory for Lamma Games


# مصنع «اكتشف الفرق» — لمّة

ينتج هذا المستودع أزواج صور «اكتشف الفرق» تلقائيًا من صور Wikimedia Commons الحاصلة على تصنيف «صورة جيدة» (Quality images)، ويضيفها إلى مكتبة اللعبة على Cloudflare R2 دون تحديث الموقع.

## كيف يعمل
1. **الصور:** يبحث عبر واجهة MediaWiki الرسمية داخل تصنيف Quality images (أكثر من 350 ألف صورة راجعها مجتمع Commons) بقائمة مواضيع متدوّرة، ويأخذ فقط الصور الأفقية بعرض 2000 بكسل فأكثر، وبرخص CC0 أو الملك العام أو CC BY أو CC BY-SA، ويستبعد الصور المقيدة بحقوق الأشخاص. كل صورة تُستخدم مرة واحدة، وتُستبعد الصور شبه المكررة ببصمة رقمية (`state/registry.json`).
2. **فهم المشهد:** كاشف أشياء (YOLOX) يجد الأكواب والكتب والكراسي والدراجات واللافتات… ثم يقصّ كل شيء بحدوده الحقيقية (GrabCut). وتقسيم الصورة يجد التفاصيل الصغيرة (نوافذ، حروف، أحجار، أوراق).
3. **الفروق:** حذف شيء مع إعادة بناء ما خلفه (LaMa)، أو نسخه إلى مكان مناسب، أو إزاحته، أو قلبه. لا تغيير ألوان ولا أشكال مرسومة.
4. **بوابة الجودة:** يُرفض كل تعديل باهت، أو بأثر ضبابي، أو بظل للشيء المحذوف، أو بلون/ملمس لا يشبه ما حوله، وكل زوج بفروق متجمعة أو تغيير خارج المناطق المسجّلة.
5. **المستوى:** يُحدَّد بحجم الفروق وتباينها وازدحام المشهد.
6. **النشر:** الصورتان (WebP) إلى `pairs/`، والفهرس إلى `catalog/` على R2. تقرأ اللعبة الفهرس عند كل جولة.

## الإعداد (مرة واحدة)
- **Settings ← Secrets and variables ← Actions ← New repository secret:**
  - لا يلزم أي مفتاح للصور.
  - `R2_ACCOUNT_ID`, `R2_BUCKET`, `R2_KEY_ID`, `R2_SECRET` (للإنتاج)
  - `FIREBASE_DB` = `https://lamma-b3804-default-rtdb.europe-west1.firebasedatabase.app` (لإخفاء الصور المبلّغ عنها)
- **Actions ← test-run ← Run workflow:** اختبار ينتج تقريرًا في `reports/`.
- **Actions ← produce:** الإنتاج (الجدولة اليومية معطلة حتى اعتماد الاختبار).

## التراخيص
- الصور: رخص Commons الحرة تسمح بالتعديل وإعادة النشر بشرط نسبة الصورة لصاحبها وذكر الرخصة؛ يُحفظ مع كل زوج اسم المصوّر ورابط صفحة الصورة والرخصة لتعرضها اللعبة. أزواج CC BY-SA تبقى منشورة بنفس الرخصة.
- طريقة الجلب تتبع سياسة Wikimedia للبرامج الآلية: User-Agent معرِّف، اتصال واحد، ومهلة بين الطلبات.
- النماذج: LaMa وYOLOX من OpenCV Model Zoo (Apache-2.0).

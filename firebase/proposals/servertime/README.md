# اقتراح: توقيت الخادم لمحاولات «اكتشف الفرق» (غير منشور، ينتظر الموافقة)

> هذا الملف **اقتراح فقط**. القواعد المنشورة هي `firebase/database.rules.json` ولم تتغير.
> كل الاختبارات أدناه تعمل على محاكي Firebase الرسمي، ولا يصل شيء إلى قاعدة البيانات الحقيقية.

## لماذا لم يُعتمد الاقتراح الأول

جرّبت أولاً إجبار الحقل `t` في **مقاعد الغرف** على وقت الخادم (`t === now`)، والنتيجة محفوظة في `reports/rules-proposal-servertime-v1-rejected/`.

- رفض المحاكي تسجيل تحديث «الغياب» الذي يكتبه المتصفح ليُنفَّذ عند إغلاقه (`onDisconnect`).
- لذلك صار إغلاق المتصفح يحذف المقعد بدل إبقائه «غائباً»، فتعطلت استعادة الجلسات وظهور «المقدّم غائب مؤقتاً».
- فشلت ثلاثة اختبارات في الموقع الرسمي v3.3 وفي النسخة التجريبية: إغلاق متصفح لاعب، وإغلاق تبويب المقدّم، وعجلة الحظ.

**لهذا لا يمسّ الاقتراح الثاني المقاعد إطلاقاً.**

## نص التعديل (الإصدار الثاني)

التعديل إضافة مكان جديد فقط، دون تغيير أي قاعدة موجودة:

```json
"taps": {
  "$room": {
    ".read": "auth != null && $room.matches(/^lmp?3-[0-9]{4}$/)",
    "$uid": {
      ".write": "auth != null && (auth.uid === $uid || (!newData.exists() && root.child('hosts').child($room).child('u').val() === auth.uid))",
      ".validate": "$room.matches(/^lmp?3-[0-9]{4}$/) && newData.hasChildren(['e', 't']) && newData.child('t').val() === now",
      "e": { ".validate": "newData.isString() && newData.val().length <= 6000" },
      "t": { ".validate": "newData.val() === now" },
      "$other": { ".validate": false }
    }
  }
}
```

ملف القواعد الكامل المقترح: `database.rules.json` في هذا المجلد.

## المعنى

- **مكان المحاولات:** كل جهاز يكتب محاولاته المشفّرة في «اكتشف الفرق» في `taps/<الغرفة>/<هوية الجهاز>`.
- **الوقت:** يرافق كل كتابة وقت الخادم لحظة وصولها (`t`)، ولا يقبل الخادم غيره.
- **ما يُمنع:**
  - كتابة وقت يختاره الجهاز، مبكراً كان أو متأخراً.
  - تغيير المحاولة مع إبقاء وقت قديم.
  - الكتابة باسم جهاز آخر.
- **الحذف:** يستطيع المقدّم (صاحب قفل الغرفة) حذف هذه المحاولات بعد الجولة، ولا يستطيع غيره حذف محاولات جهاز آخر.
- **القراءة:** للأجهزة المسجّلة في الغرفة فقط. المحتوى مشفّر لكل لاعب، فلا يكشف شيئاً.

## الأثر

- **عجلة الحظ، والحروف، والمسابقات، والألغاز:** لا أثر، فالقواعد التي تستخدمها لم تتغير.
- **استعادة الجلسات:** لا أثر، فالمقاعد وتحديث الغياب كما هي اليوم.
- **الموقع الرسمي الحالي (v3.3):** لا أثر، فهو لا يستخدم المكان الجديد.
- **«اكتشف الفرق»:** بالبناء الخاص `LAMMA_SRVTIME=1`، يرتّب جهاز المقدّم المحاولات حسب لحظة وصولها **إلى خادم Firebase**.
  - البديل الحالي: لحظة وصولها إلى جهاز المقدّم.
  - يُعلَن الفائز بعد نحو ثانية بدلاً من 0.3 ثانية، انتظاراً للكتابات التي ما زالت في الطريق.
- **النسخة التجريبية الحالية:** تبقى على توقيت جهاز المقدّم حتى تُعتمد القاعدة.

## ما لا يحققه التعديل

- **فرق سرعة الإنترنت يبقى:** توقيت الخادم يقيس لحظة وصول المحاولة إلى خادم Firebase. اللاعب الذي شبكته أبطأ تصل محاولته متأخرة بقدر ذلك.
- **ما يُلغى فقط:** الجزء الذي يقع بين الخادم وجهاز المقدّم، وتأخر جهاز المقدّم نفسه.
- **ضغطتان سريعتان من اللاعب نفسه:** إن جُمعتا في كتابة واحدة يُسجَّل لهما وقت الكتابة الأخيرة. هذا قد يؤخر صاحبهما فقط ولا يفيده.

## الاختبارات (على المحاكي فقط)

مسار العمل: `.github/workflows/rules-proposal-servertime.yml`

1. **اختبارات القواعد الحالية كلها** (`tests/rules/rules.test.mjs`) بالقواعد المقترحة.
2. **اختبارات المكان الجديد** (`tests/rules/servertime.test.mjs`):
   - الكتابة بوقت الخادم تنجح.
   - رفض وقت الجهاز.
   - رفض الوقت المبكر.
   - رفض تغيير المحاولة دون وقت جديد.
   - رفض الكتابة باسم جهاز آخر وحذف محاولاته.
   - حذف المقدّم للمحاولات بعد الجولة.
   - بقاء استعادة الجلسات بعد إغلاق المتصفح كما هي.
3. **الموقع الرسمي v3.3** (بناء المحاكي): كاملاً بالألعاب الخمس.
4. **النسخة التجريبية الحالية من «اكتشف الفرق»** مع الألعاب الأخرى واستعادة الجلسات.
5. **«اكتشف الفرق» بتوقيت الخادم** (`tests/emu-site-spot-srv`).

## التطبيق (لاحقاً، بعد الموافقة فقط)

1. **القواعد:** نسخ `database.rules.json` من هذا المجلد إلى `firebase/database.rules.json`، ثم نشره بالطريقة المعتمدة.
2. **الموقع:** بناء الموقع بـ `LAMMA_SRVTIME=1`، وتشغيل الاختبار الحي.
3. **الترتيب:** يجب نشر القاعدة **قبل** الموقع. لو سبقها الموقع لرفضت قاعدة البيانات كتابة المحاولات.
4. **خطة الرجوع:** إعادة البناء دون `LAMMA_SRVTIME`، ثم إعادة ملف القواعد السابق.
